### C02-01  Selector-projector idempotence and orthogonality
- Lines: L1250-L1258
- Statement: Let 𝒜 be a (unital, *-)algebra; for each P in a finite index set 𝔄 let B_P ⊆ 𝒜 be a subalgebra and E_P : 𝒜 → B_P a linear map with E_P|_{B_P} = id (so E_P^2 = E_P) and the left bimodule property E_P(bY) = b E_P(Y) for b in B_P. Let e_P in B_P with e_P^2 = e_P, e_P e_Q = 0 (P ≠ Q), Σ_P e_P = 1. Define Π_P X := E_P(e_P X). Then Π_P^2 = Π_P and Π_P Π_Q = 0 for P ≠ Q.
- Kind: A
- Difficulty: easy
- Depends on: none
- Notes: Proof: E_Q(e_Q X) = E_Q(e_Q e_Q X) = e_Q E_Q(e_Q X) (left module property), so Π_PΠ_Q X = E_P(e_P e_Q E_Q(e_Q X)) = 0 for P≠Q, and Π_P^2X = E_P(e_P E_P(e_P X)) = E_P(E_P(e_P^2 X)) = Π_P X. Only the LEFT module property and e_P ∈ B_P are needed; positivity/state-preservation of E_P is not used. Σ e_P = 1 is not needed for these two identities.
