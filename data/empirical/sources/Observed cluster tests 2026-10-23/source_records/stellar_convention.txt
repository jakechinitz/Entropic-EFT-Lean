Source inspection before reduction: Ghizzardi et al. arXiv:2007.01084 section 4.1 explicitly says stellar profiles are PROJECTED cumulative masses. Only the R500 table is deprojected using 0.75. The raw and smoothed FITS profiles remain projected. We implement a declared spherical gNFW geometrical correction with inner slope 1.64 and scale chosen once to reproduce D(R500)=0.75; this radial extension is our approximation, not a released deprojection. We retain 0 <= Mstar_3D <= Mstar_projected as a geometrical envelope for the measured stellar component and show a doubled-star sensitivity for missing ICL/population systematics. That doubled-star scenario is not a hard astrophysical upper bound. All radial statements below 0.1 R500 are excluded from the principal test. Five clusters lacking stellar data receive gas-only lower-bound diagnostics, not complete baryon fits.

Two release details: A2319 and A644 smoothed stellar radii differ slightly from raw-radius times header R500. Use the smoothed extension's explicit kpc radii without silently rescaling. Error column conventions also differ: fgas MGAS_LO/HI are error magnitudes; smoothed stellar MSTAR_LO/HI are absolute bounds. Keep these distinct. Published gas/stellar tables are not identical to this archived FITS reduction; report the actual FITS release values rather than silently replacing them.
