STOCK ADJUSTMENT AND ORIENTATION MEMORY
Read Stock adjustment and orientation memory.pdf (6 pages).

RESULT
A contact acting only within retained angular sectors can relax radial
occupation while preserving angular memory. Eight Lean theorems verify the
finite positive map and its invariants. A nearest-neighbour density model
tracks a changing a0 without creating stock; positive spherical orbit
populations separately demonstrate approximate endpoint compatibility at
fixed initial angular-momentum-bin masses.

This resolves an asserted mathematical incompatibility. It does not finish
the physical closure. The new central-contact selection rule, its equilibrium
radial populations, its mechanical energy source, and its coupling to the
self-gravitating tilted halo have not been derived or jointly validated.
The manuscript remains paused and all 21 source hashes are unchanged.

NUMERICAL RESULTS
- Selected tau=0.5 Gyr: present stock-force lag about 2.2% at 5-80 kpc.
  Independent doubled-grid/halved-step change <=0.000313 in force ratio.
  Maximum historical lag from z=2.5 is 12.9%, so present tracking does not
  establish exact high-redshift RAR agreement.
- Selected tau=0.25 Gyr: present lag about 1.05%; historical maximum 6.98%.
- Stock mass conserved to 1.2e-13; protected-sector mass to 8.4e-16.
- Smooth fixed-L orbit endpoint: independent force error <=1.23% (5-80 kpc),
  shell-mass L1 1.57%, global virial residual 0.127%. Its optimizer reached
  its iteration limit. Feasible weights are assessed directly; there is no
  claim of an optimum or a complete continuous-density solution.
- Earlier sparse orbit fits have much larger held-out shell residuals;
  all results are retained and reported.
- Mechanical expansion work from z=2.5 is about 1.94e-7 of stock rest energy.
  The energy reservoir is not identified by this arithmetic.

REPRODUCTION
The scripts deliberately refuse to overwrite named results. Copy the Python
sources into a fresh sibling research directory before reproducing outputs,
or give stock_model.py a new --tag. The spherical and transport calculations
require Python, NumPy, SciPy and Matplotlib; they do not import old simulations.

Examples from the new directory:
python stock_model.py --z 1 --tag fixed_L_z1
python stock_model.py --z 2.5 --tag fixed_L_z25
python stock_model.py --z 1 --tag fixed_L_z1_refined --nl 192 --ne 96 --nrad 96 --nquad 384
python stock_model.py --z 2.5 --tag fixed_L_z25_refined --nl 192 --ne 96 --nrad 96 --nquad 384
python stock_model.py --z 2.5 --tag fixed_L_z25_smooth --nl 256 --ne 96 --nrad 192 --nquad 768 --smooth
python transport_checks.py
python independent_checks.py

The original sparse files were generated by stock_model_original.py; the
current implementation excludes numerically almost-circular quadrature
orbits and records the smooth-fit options. Use the original implementation
for exact reproduction of those earlier results.

For the smooth independent check, call
independent_checks.verify_orbits('fixed_L_z25_smooth') and save to a new file.
For Lean, run lake env lean /absolute/path/RetainedRelaxation.lean in a
Lean/mathlib 4.19 project. The existing Unified closure toolchain was used.
verify_and_plot.py additionally expects the original workspace manifest and
toolchain for preservation and proof checks.

Build the research note from the workspace root using
python .organization/build_pdfs.py --tex "02 Research/Stock adjustment resolution 2026-10-21/Stock adjustment and orientation memory.tex"
This only typesets the note; it does not rerun the scientific calculations.
